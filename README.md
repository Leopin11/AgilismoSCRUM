#NextBuy
Este proyecto se trata de un e-commerce que facilita al usuario adquirir productos tecnológicos que normalmente no son vendidos en Colombia.
##Equipo: 
-Andrés Duque
-Leonardo Pinto
-Carlos Córdoba
##Tecnologías:
-HTML
-CSS
-JavaScript
-Java
-SQL Server
-SpringBoot
-React
##Organización:
El proyecto se desarrolla utilizando Scrum y se organiza en diferentes Sprints. 
##Estado del proyecto:
Fase inicial de planificación y definición.
