# HU-01 · Persona y Registro de Usuario Global
 
## Historia de Usuario
 
**Como** usuario internacional o residente local
 
**Quiero** registrarme con mis datos básicos, residencia activa e idioma preferido
 
**Para** interactuar en la comunidad global de MapPal.
 
## Story Points
 
**13 puntos**
 
### Criterios de Aceptación
 
1. El sistema debe permitir el registro mediante un identificador único.
2. El sistema debe calcular automáticamente la edad a partir de la fecha de nacimiento.
3. El sistema debe asignar un valor inicial de Karma al usuario registrado.
4. El sistema debe permitir configurar una residencia activa.
5. El sistema debe soportar múltiples idiomas en la interfaz.

**Para** demostrar mi nivel de confianza dentro de la comunidad.

**13 puntos**
 
### Criterios de Aceptación

2. El sistema debe mostrar los aportes aprobados por la comunidad.

# HU-04 · Publicación y Verificación de Alertas Comunitarias
 
## Historia de Usuario
 
**Como** usuario que identifica un riesgo de seguridad
 
**Quiero** publicar alertas georreferenciadas
 
**Para** advertir a otros viajeros sobre posibles riesgos.
 
## Story Points
 
**21 puntos**
 
### Criterios de Aceptación
 
1. El sistema debe registrar coordenadas GPS para cada alerta.
2. El sistema debe permitir adjuntar fotografías.
3. El sistema debe clasificar alertas según su nivel de riesgo.
4. El sistema debe permitir validación comunitaria mediante votos.
5. El sistema debe mostrar protocolos preventivos asociados a la alerta.
