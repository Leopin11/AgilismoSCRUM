# Product Backlog - E-commerce

## 1. Registro de Usuario – Admin
### Features
- **Formulario Cliente**: Crear cuenta con correo y contraseña, pedir nombre, edad y dirección.
- **Formulario Admin**: Crear cuenta con correo corporativo y contraseña, validación por SMS y correo.



## 2. Filtros de Búsqueda
### Features
- Buscar por categoría.
- Buscar por nombre de producto.
- Buscar por rango de precio.
- Combinación de filtros (categoría + precio + nombre).



## 3. ChatBot
### Features
- Respuestas frecuentes (FAQ).
- Escalamiento a humano.
- Integración con pedidos.



## 4. Suscripciones
### Épica 1: Incentivos para usuarios recurrentes
- **Feature:** Promociones exclusivas.


### Épica 2: Incentivos para usuarios intermitentes
- **Feature:** Bonos de reactivación.


## 5. Recuperar la contraseña
### Features
- Restablecimiento de contraseña por correo electrónico.
- Validación de token caducado.



## 6. Pasarela de pagos
### Épica 1: Procesamiento de pagos
- **Feature:** Gestión y procesamiento de tarjetas de crédito y débito.

### Épica 2: Integración con billeteras digitales
- **Feature:** Pagos móviles y billeteras digitales.

### Épica 3: Panel de control
- **Feature:** Gestión de transacciones.

### Épica 4: Emisión de comprobantes
- **Feature:** Envío automático de facturas digitales y recibos.
